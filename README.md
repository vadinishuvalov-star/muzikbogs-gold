# МЮЗИКБОГС — «Золотой эфир»

Видоизменённая версия сайта радиостанции [МЮЗИКБОГС](https://vadinishuvalov-star.github.io/muzikbogs-radio/) — с сохранением всей структуры, контента и функций (плеер, расписание, фильтры, эквалайзер, RU/EN, светлая/тёмная темы). Оригинальный репозиторий не изменялся.

## Что взято из референсов

- **RTÉ Gold** — «золотая» палитра и ощущение радио «золотого века»;
- **FM Classic (Siracusa / Posadas)** — крупная вывесочная типографика, жёсткая сетка, акцент на decades;
- **Old Hits 60/70/80/90** — полоса десятилетий и бейджи «без рекламы»;
- **Radio Saudade / Recuerdos Retros** — тёплая ностальгическая редакционная подача, винильные мотивы;
- **Radio Delta FM / Atomik Radio / RadioHits** — чистая навигация, крупный ON-AIR, плашки эфира.

## Дизайн

- Инк + пергамент + латунь вместо неона; акцент — терракота.
- Шрифты: Bebas Neue (вывеска), Playfair Display (курсивные акценты), Manrope (текст).
- Винтажные текстуры: плёночное зерно, микро-линиатура, концентрические дорожки винила, латунные углы карточек.
- Тёмная тема «студия» и светлая тема «пергамент» обе полностью проработаны.
- Частицы логотипа и спектр эквалайзера перекрашены под латунную палитру.
